## 七、对比分析

### 7.1 新旧训练对比

| 维度 | 旧 v8s (结构张量) | v1 baseline (HSV) | v2 stable (HSV) |
|------|-------------------|-------------------|-----------------|
| 模型 | **v8s 11M** | v8l 44M | v8l 44M |
| Epoch 1 | mAP50=0.712 | 0.201 | — |
| Epoch 5 | **0.837** | 0.370 | 0.319 |
| Epoch 10 | **0.839** | 0.402 | (待观测) |
| NaN | 0 | **11** | **0** |
| amp | false | true | false |
| lr0 | 0.0002 | 0.001 | 0.0002 |

### 7.2 关键发现

1. **AMP 是 NaN 源头**：v1 (amp=true) 11 次 NaN，v2 (amp=false) 0 次
2. **lr0=0.001 对 v8l/95类过高**：v8s 用 0.0002 平稳收敛，v8l 用 0.001 反复崩塌
3. **hsv_s=0 失去正则化**：禁用 HSV 增强减少了数据多样性
4. **HSV 偏振 vs 结构张量偏振**：
   - 结构张量（边缘梯度）对 FlowCam 暗场灰度图更有效——硅藻壳纹路、细胞边界都是边缘特征
   - HSV（颜色饱和度）在暗场图像中 S 通道值整体偏低（S≈0 → DoLP≈0），偏振信号弱
5. **暗场图像 × HSV 方法的本质矛盾**：HSV 映射假设颜色饱和度与偏振度正相关，但 FlowCam 暗场成像是灰度为主的——这个矛盾是根本性限制
