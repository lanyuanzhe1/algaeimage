## 1. HSV 偏振模拟方案

### 背景
基于 Yan et al. (Photonics 2024) 的 RGB→HSV→AoP/DoLP/S₀ 映射方案，在本地实现了替代原有结构张量法的偏振模拟管线。

### 实现
- `hsv_polarization.py`：核心算法，H→AoP, S→DoLP, V→S₀，Stokes 公式反算 I0/I45/I90/I135
- `run_pipeline.py`：完整管线脚本（Stage1→2→3）
- 依赖模块从 `algae_guardian/` 复制到本地，不修改原始代码

### 管线输出（293 张 FMPD）

## 2. RDN 输出语义错配

### 发现
RDN 训练目标（`generate_rdn_data.py`）：输出 I0'/I45'/I90'/I135'（伪偏振强度通道）
推理使用（`polarization_sim.py:289-293`）：输出被当作 S0/S1/S2 斯托克斯参数

```python
S0_recon = recon_3ch[:, :, 0]              # RDN学的是I0'，推理当S0
S1_recon = recon_3ch[:, :, 1] * 2 - 128    # RDN学的是I45'，推理当S1
S2_recon = recon_3ch[:, :, 2] * 2 - 128    # RDN学的是I90'，推理当S2
```

RDN本质是4→4去噪自编码器，输出≈输入的增强版，工程上可能有效但语义不对齐。

## 3. DoLP 饱和问题 ⚠️

### 现象
293 张 FMPD 图像经完整管线后，DoLP_recon 均值 0.991，范围 [0.956, 0.9998]，几乎全图"完全偏振"。

### 根因
`*2-128` 中心化将 uint8 [0,255] 映射到 [-128, 382]，S1/S2 幅值远超 S0 归一化范围，导致：
```
DoLP = sqrt(S1² + S2²) / (S0 + 1e-10)  →  远超 1.0 → 被 clip 到 1.0
```

### 影响
- I_enh v2 公式中 `-γ·DoLP` 退化为常数 -0.35，失去自适应去散射能力
- `β·AoP_mod·DoLP` 项仍在随 AoP 变化，保留部分偏振结构增强
- DoLP 饱和不致命，但削弱了公式设计意图

### 真实 DoLP 参考值
| 场景 | DoLP 范围 |
|------|----------|
| 纯水/背景 | 0~0.05 |
| 藻类细胞壁(双折射) | 0.1~0.3 |
| 散射/反射 | 0.5~0.8 |
| 理想消光 | ~1.0（几乎不存在） |

### 待办
观察 `yolo_input_hsv/` 中藻类 vs 背景对比度，如果足以分辨则先上 YOLO 检测。结果说话。

## 4. config.py 类定义修复

### 问题
`ALGAE_CLASSES` 定义了 6 类虚构中文藻名（球形棕囊藻、微囊藻等），与训练模型 best.pt 的 5 类完全不匹配。

ALGAE_CLASSES = {

训练模型: YOLOv8l, FMPD 293 张, mAP50=0.429, 5 类

## 6. 颜色信息备注

YOLO 藻类检测目前以灰度图形状/结构特征为主，颜色信息不是关键区分因素。green_ratio > 0.33 假设不适用于硅藻（金棕色）、蓝藻（蓝绿色）、死细胞等。后续如果要引入颜色需重新评估。
