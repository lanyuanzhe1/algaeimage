# RGB → 三方向偏振图模拟方法调研

> 调研日期：2026-05-07
> 目标：从普通RGB显微藻类图像，模拟DoFP偏振相机的 0°、45°、90° 三个偏振方向通道

---

## 方法一：基于图像梯度的伪偏振生成 ⭐ 推荐

**来源**：*A Method for Generating Pseudo-Polarization Images*, IEEE Signal Processing Letters, 2024

### 原理
- 使用**结构张量（Structure Tensor）** 计算每个像素的局部梯度方向和强度
- 边缘/纹理区域 → 偏振响应强（边界处的散射光具有高偏振度）
- 平坦区域 → 偏振响应弱
- 镜面反射区域 → 特定偏振角响应

### 算法流程

```
RGB图像
  → 灰度化
  → 计算梯度 Gx, Gy（Sobel）
  → 结构张量 J = [Gx², GxGy; GxGy, Gy²]
  → 特征值 λ1, λ2 → 各向异性度 DoA = (λ1-λ2)/(λ1+λ2)
  → 主方向 θ = 0.5·arctan2(2GxGy, Gx²-Gy²)
  
  I0  = I · (1 + DoA · cos²(θ))
  I45 = I · (1 + DoA · cos²(θ - 45°))
  I90 = I · (1 + DoA · cos²(θ - 90°))

  其中 I = 原图亮度
```

### 优点
- 计算简单，不需要训练数据
- 能模拟偏振对边缘/纹理的增强效果
- 已在本项目的 `ml/reconstructor.py` 中实现为 `simulate_from_rgb()`

### 缺点
- 对透明/半透明微藻的效果有限
- 不模拟散射和浑浊水体的偏振效应

## 方法二：SPDRDN 三通道变换法

**来源**：项目已有的 SPDRDN 代码库，`utils.py` 中的 `new_i0/i45/i90` 函数

### 原理
将 RGB 三通道视为三种不同的偏振响应，通过线性组合映射到 I0、I45、I90：

```python
def new_i0(r, g, b):   # r,g,b为三通道
    s0 = 2/3 * (r + g + b)
    s1 = r + b - 2*g
    new = 0.5 * (s0 + s1)    # → I0
    return new
```

### 优点
- 代码已存在，零成本
- 保持三个通道的多样性

### 缺点
- 物理意义较弱（RGB ≠ 偏振响应）
- 输出的偏振特征与真实DoFP差异较大

## 方法三：CycleGAN 无监督域迁移

**来源**：*DoLP and AoP Synthesis from DoFP using CycleGAN*, Optics Communications, 2023

### 原理
使用 CycleGAN 在**非配对数据**上学习 RGB ↔ 偏振图像之间的映射：
- 收集普通显微图像（源域）
- 收集少量偏振显微图像（目标域，可用SPDRDN仿真数据）
- CycleGAN 学习风格迁移

### 优点
- 不需要配对数据集
- 能学习真实的偏振特征分布

### 缺点
- 需要至少少量真实偏振图像
- 训练复杂度高，调参成本大

## 方法四：物理成像模型正向仿真

**来源**：Qiu et al., *Linear Polarization Demosaicking for Monochrome and Colour DoFP*, CGF 2021

### 原理
基于偏振成像的物理模型进行正向渲染：
1. 假设藻类细胞为球状/椭球状散射体
2. 使用 Mie 散射理论计算散射光的偏振态
3. 模拟暗场照明下的 0°/45°/90°/135° 四通道响应
4. 应用 DoFP 2×2 微偏振阵列采样

### 优点
- 物理准确，可模拟不同藻种形态的偏振响应
- 可控制浑浊度、散射强度等参数

### 缺点
- 需要已知藻类光学参数（折射率、尺寸分布）
- 计算量大，实现复杂

## 方法五：简单通道分离 + 偏振增强（当前已实现）

**来源**：本项目的 `detection_service.py`

### 原理
将RGB三通道直接映射到偏振处理的输入：

```python
S0 = image[:,:,0]          # R通道 → 总光强
S1 = image[:,:,1] - 128    # G通道偏移 → 0°/90°差分
S2 = image[:,:,2] - 128    # B通道偏移 → 45°/135°差分
DoLP = sqrt(S1² + S2²) / (S0 + ε)
AoP = 0.5 * arctan2(S2, S1)

# 应用 I_enh 增强
I_enh = Norm(S0 + λ1·S0 + λ2·AoP + λ3·DoLP)
```

### 优点
- 最简单，已在 pipeline 中运行
- 能体现出偏振增强效果

### 缺点
- 物理映射不真实
- YOLO 训练时迁移到真实偏振数据可能有域差异
