混合方案：Dashboard 首页设计

Dashboard 是默认首页。它应该展示什么？以下是两种侧重点不同的方案

A

监控型 Dashboard

模仿模板风格：管线状态可视化 + 统计指标卡 + 最近检测快览 + 风险摘要。强调"看"——打开页面就能感知系统运行状态。检测按钮作为突出 CTA 入口。

B

工具型 Dashboard

首页直接展示上传检测区域 + 快捷操作 + 下方放统计图表。强调"做"——打开页面就能开始检测。统计和历史概要作为辅助信息放在下方。
