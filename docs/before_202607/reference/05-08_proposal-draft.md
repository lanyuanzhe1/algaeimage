# 藻影卫士：面向有害藻华早期预警的水下智能偏振监测系统

## 一、背景

### 1.1 有害藻华已经从局部生态问题演变为水安全与产业安全问题
有害藻华是近岸海域、湖泊、水库和养殖水体中常见且危害严重的生态灾害。藻类在适宜水温、营养盐输入、水动力条件和光照条件下快速增殖，会造成水体变色、溶解氧下降、生态群落结构失衡，严重时还会释放毒素或形成大规模生物团聚，对渔业养殖、饮用水安全、海洋牧场、核电冷源和近岸生态管理造成直接影响。球形棕囊藻等藻类可形成大规模囊体和黏性团聚物，对核电站冷源取水系统、水库取水口和工业循环水系统造成堵塞风险，其危害范围广、识别难度高。

### 1.2 传统监测方式存在明显滞后，难以支撑“早发现、早预警、早处置”
现有藻华监测主要依赖三类手段：一是人工采样与实验室显微镜镜检，流程长、频次低；二是水质传感器监测环境指标，无法直接给出“致灾生物是否出现”的判定；三是遥感大范围监控，但在近岸浑浊水体对微小原因种的早期识别能力严重不足。

### 1.3 现有高端设备痛点与低成本全链路方案的市场机会
国际高端原位成像产品（如 FlowCAM、ZooScan）昂贵且部署门槛高，难以在养殖场、水库大规模布点。本项目的机会在于突破极高成本硬件限制，针对浑浊水体，依托光电智能融合算法（偏振成像+去散射处理+致灾藻种识别），推出一套“小型化、全链路偏振、可连续识别、可联网”的极早期预警系统。

## 二、产品介绍

### 2.1 产品定义与核心价值
暂定名为“藻影卫士”。它是一套面向有害藻华早期预警的水下系统，能够在水下原位利用偏振相机采集微米级藻类多角度偏振图像，并通过 SPDRDN 等深度重建结合 AI 目标检测算法，识别并提取重点微藻，为高浑浊海域或水库用户提供从原位图像、物理重构到终端预警的一体化工具。

### 2.2 产品要解决的核心逻辑
将复杂浑浊水体中的目标从“看不见（散射掩盖）”和“看不准（形态相似）”通过“偏振捕捉 + 残差重建”解决；把繁琐、极高成本的光电装备，通过“算法降噪补强+低成本偏振硬件”，打造成可快速、多点部署的产业痛点解决方案。

## 三、技术方案（核心壁垒）

系统总体技术路线全新升级为“偏振感知-深度重建-智能探测”的光电协同双重闭环，具体技术链条拆解为四大阶：

### 3.1 第一阶：原位多角度偏振光学成像 (感知源头)
**获取不可见的高维物理信息**
自然界中，藻类细胞壁等微观突变结构对偏振光具有强烈的调制作用，而水体杂质的无序散射光则往往表现为非偏振或低偏振态。我们采用**全分辩率偏振相机**，在原位水下暗场照明激发下，能够同步瞬间捕获三个关键物理偏振方向的原始图像（即偏振化角分别为 **$0^\circ$、$45^\circ$、$90^\circ$** 的方向偏振图像 $I_0, I_{45}, I_{90}$）。
利用这三个分量，我们在光电底层就已切断了水体背景散射带来的退化，通过光学 Stokes 矢量方程准确提取出总强度 $S_0$ 以及刻画偏振态的 $S_1, S_2$。这为后续解析微藻的“线偏振度 (DoLP)”与“偏振角 (AoP)”等高维特征立下坚实的信源基础。

### 3.2 第二阶：基于 SPDRDN 的偏振特征高保真重建 (降噪与解耦)
**突破水下弱光与极限噪声瓶颈的大模型**
水下原位成像依然会引入泊松散粒噪声和高斯暗电流噪声。传统的解析法在低信噪比下会产生剧烈噪声放大，掩盖真正的微藻特征。本项目的核心计算底座——**残差稠密偏振重建网络（SPDRDN）**登场。
1. **多通道堆叠特征输入**：前置获取的 $[I_0, I_{45}, I_{90}]$ 偏振图降维至 3 通道输入网络，建立端到端映射。
2. **残差稠密聚合重建**：网络内部多级稠密级联模块，充分提取藻类边缘特征并抑制高频偏振噪声。
3. **物理特征分治输出**：模型极其精准地回归纯净偏振特征图（洁净的 $AoP$、$DoLP$ 分布）。这一步彻底完成了浑浊水底环境信号的“洗霾”过程，细胞壁折射细节在图谱上被指数级放大。

### 3.3 第三阶：后处理光学特征图像增强优化 (靶向凸显)
经过深度学习重建后的图谱虽然干净，但为了达到 AI 目标检测的极限精确率，我们实施了一套图像最后优化流程：
1. **自适应色阶对比度增强 (CLAHE)**：对 DoLP 图像进行分块色阶自适应调整，极大拉开半透明藻类与其背景差异。
2. **暗通道先验的残余微散射抑制**：采用基于先验的暗通道去散射（Descatting）处理。这一步如同装上“偏光透镜”，背景沉降为极深色，微藻轮廓极其显眼地转化为高亮度、高锐度目标。这就是喂给AI的最佳“弹药”。

### 3.4 第四阶：YOLOv8 智能致灾藻种探测与预警 (末端决策)
我们将上一阶段淬炼出的“最优融合偏振增强图像”馈送至调优后的 **YOLOv8 微观目标智能检测模型**。
相对于直接硬喂浑浊 RGB 的同行，我们凭借前端硬件物理切割、SPDRDN重构及优化多重提纯，形成了极高的降维打击：
* 在混合打样中，对球形棕囊藻等微观重点目标的**识别精确率跃升至 90% 以上**；
* 即便面对形态极度相似的小球藻，系统亦能实现**趋近于 0 的误检率**；
* 处理延迟稳定在 **0.3 秒左右**，完美支撑动态并发预警及随水温、盐度、营养盐进行的复合双重环境证据决策。

## 四、商业与落地

### 4.1 数据闭环与落地衍生
“偏振物理捕获—深度重建—图像提纯—目标检测预警”的全栈链条，不仅规避了单一算法易被抄袭的软肋，还降低了传统仪器昂贵的成本依赖。随着布点增加，本系统将积累多海区、多季节、多浊度的藻种偏振识别库，直接夯实数据壁垒，形成“硬件铺设+云端预测增值服务”的长效收益模式，极具商业推广与海洋牧场防灾潜力。
